# AWS Services Overview

## 1. Compute Services
- **EC2 (Elastic Compute Cloud):** Virtual servers to run applications.
- **Lambda:** Serverless computing service to run code without provisioning servers.
- **Elastic Beanstalk:** Platform as a Service (PaaS) for deploying and managing applications.
- **Lightsail:** Simplified virtual servers, storage, and networking for small projects.

## 2. Storage Services
- **S3 (Simple Storage Service):** Object storage for storing and retrieving any amount of data.
- **EBS (Elastic Block Store):** Persistent block storage for use with EC2.
- **EFS (Elastic File System):** Scalable file storage for Linux-based workloads.
- **Glacier:** Low-cost, long-term archival storage.

## 3. Database Services
- **RDS (Relational Database Service):** Managed relational databases like MySQL, PostgreSQL, and SQL Server.
- **DynamoDB:** NoSQL database for low-latency, high-performance needs.
- **Redshift:** Data warehouse for large-scale analytics.
- **ElastiCache:** In-memory caching service for real-time use cases.

## 4. Networking Services
- **VPC (Virtual Private Cloud):** Isolated networks to run resources securely.
- **Route 53:** Scalable DNS and domain name registration service.
- **CloudFront:** Content delivery network (CDN) for fast content delivery.
- **Elastic Load Balancing (ELB):** Automatically distributes traffic across multiple instances.

## 5. Developer Tools
- **CodePipeline:** Continuous integration and delivery.
- **CodeBuild:** Automated build and testing service.
- **CodeDeploy:** Automates deployment to EC2, Lambda, or on-premises servers.
- **CodeCommit:** Managed source control service like Git.

## 6. Machine Learning and AI
- **SageMaker:** Fully managed service to build, train, and deploy ML models.
- **Rekognition:** Image and video analysis.
- **Polly:** Text-to-speech service.
- **Comprehend:** Natural language processing for insights from text.

## 7. Security and Identity
- **IAM (Identity and Access Management):** Manage access to AWS resources.
- **AWS Shield:** DDoS protection.
- **Macie:** Data discovery and protection using AI.
- **Secrets Manager:** Manage and rotate sensitive data like API keys.

## 8. Management and Governance
- **CloudWatch:** Monitoring and observability service for AWS resources.
- **CloudTrail:** Logs user activity and API usage.
- **Systems Manager:** Centralized operational management for resources.
- **Cost Explorer:** Helps manage and optimize AWS costs.

## 9. Migration and Transfer
- **AWS DMS (Database Migration Service):** Migrate databases to AWS.
- **Snowball:** Data transfer appliance for large data migrations.
- **Application Migration Service:** Simplifies migrating on-premises applications to AWS.

## 10. Analytics
- **Athena:** Query data directly from S3 using SQL.
- **EMR (Elastic MapReduce):** Big data processing using Hadoop and Spark.
- **Kinesis:** Real-time streaming data processing.
- **QuickSight:** BI tool for visualizing and analyzing data.

## 11. Internet of Things (IoT)
- **IoT Core:** Connect and manage IoT devices securely.
- **Greengrass:** Enables local processing and machine learning on devices.

## 12. Application Integration
- **SQS (Simple Queue Service):** Message queuing service.
- **SNS (Simple Notification Service):** Push notification service.
- **Step Functions:** Orchestration for workflows and microservices.

## 13. Content Delivery and Edge Services
- **CloudFront:** Content delivery network for low-latency content access.
- **Global Accelerator:** Enhances global application availability and performance.

## 14. AR & VR
- **Sumerian:** Build and deploy AR/VR applications.

## 15. Blockchain
- **Amazon Managed Blockchain:** Build scalable blockchain networks.
